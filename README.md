# 🚆 Public Transport Usage Analysis Dashboard | Power BI

## 📌 Project Overview

The **Public Transport Usage Analysis** project is an interactive dashboard developed using Microsoft Power BI to analyze public transportation usage and passenger travel patterns. The dashboard provides insights into passenger demand, revenue generation, route performance, delays, and the impact of weather conditions on public transport.

The main objective of this project is to transform transportation data into meaningful visual insights that can help identify usage trends, understand passenger behavior, and support data-driven decision-making.

## 🎯 Project Objectives

- Analyze passenger usage across different public transport modes.
- Identify monthly passenger trends and peak travel periods.
- Track total passenger counts and fare revenue.
- Identify the busiest routes and compare route performance.
- Analyze average delays across different transport modes.
- Understand the impact of rainy and clear weather conditions on delays.
- Compare passenger usage across weekdays and weekends.

## 🛠️ Tools and Technologies

- **Microsoft Power BI** – Dashboard creation and data visualization
- **Power Query** – Data cleaning and transformation
- **DAX (Data Analysis Expressions)** – Calculated measures and KPIs
- **CSV Dataset** – Data source
- **Data Modeling** – Relationships between fact and dimension tables

## 📊 Dashboard Features

- **KPI Cards:** Total Passengers, Total Revenue, Average Delay, and Peak-Hour Passenger Share.
- **Monthly Passenger Trends:** Tracks changes in passenger usage over time.
- **Passenger Usage by Transport Mode:** Compares usage across different modes.
- **Route Performance Analysis:** Highlights busy routes and compares passenger counts and delays.
- **Weather Impact Analysis:** Compares average delays during rainy and clear weather.
- **Day-of-Week Analysis:** Examines passenger demand across different days.
- **Interactive Filters:** Allows users to filter the dashboard by year, transport mode, and zone, where available.

## 🔍 Key Insights

The dashboard is designed to help users identify:

- Months with the highest and lowest passenger demand.
- Transport modes with greater passenger usage.
- Routes that experience higher passenger traffic.
- Differences in weekday and weekend travel patterns.
- Potential relationships between weather conditions and transport delays.
- Trends in fare revenue and peak-hour demand.

*Actual findings depend on the dataset and the filters selected in the dashboard.*

## 🚀 Project Outcome

This project demonstrates how Power BI can be used to convert raw transportation data into an interactive analytical dashboard. It combines data cleaning, data modeling, DAX calculations, and visual storytelling to make public transport trends easier to understand.
